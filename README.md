# Cours Bootstrap 5

Bienvenue dans le Github du projet fil rouge "Portfolio" associé au [cours OpenClassrooms sur Bootstrap 5](https://openclassrooms.com/fr/courses/6391096-creez-des-sites-web-responsive-avec-bootstrap-4).

J'ai réalisé ce projet pour apprendre et améliorer mes compétences Bootstrap. Je n'ai pas 100% suivi le cours mais j'ai essayé de ne me baser que sur la documentation Bootstrap pour trouver comment ressembler au plus près à la maquette fournie. J'ai aussi ajouté quelques détails pour travailler sur d'autres points.

Je n'ai pas rajouté de fichier CSS en plus, tout est formaté avec Bootstrap.

Je n'ai pas utilisé d'IA pour ce projet.

## Etapes de mon projet

- Structure de pages
  - Mise en page responsive
- Barre de navigation
- Composant progress bar 
- Carousel
- Contact form
- Modale
